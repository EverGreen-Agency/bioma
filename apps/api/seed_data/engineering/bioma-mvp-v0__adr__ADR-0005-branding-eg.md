# ADR-0005: Branding EG no Bioma

- **Status:** aprovado para MVP v0
- **Data:** 2026-07-09
- **Contexto:** mockups HM orientam fluxo e expectativa comercial, mas o produto Bioma deve parecer EverGreen.

## Decisão

O Bioma usa identidade visual EG como padrão:

- Verde Musgo Profundo: `#09231B`
- Amarelo Baunilha Claro: `#FFF4C7`
- Verde Menta Viva: `#3AC97B`
- Tipografia: Helvetica ou fallback compatível (`Helvetica Neue`, Arial, sans-serif)

As telas HM podem inspirar navegação, densidade, CRM, dashboard e calendário, mas não definem a paleta principal do produto.

## Motivos

- Bioma é produto operacional da EG, não uma cópia visual de um cliente.
- O branding precisa reforçar boutique premium e diferenciação técnica.
- Evita a repetição de UI azul/roxa genérica de SaaS.

## Direção de UI

- Interface densa, operacional e clara.
- Sem landing page como tela inicial do produto.
- Cards apenas quando forem unidades reais de informação.
- Verde musgo para base institucional e navegação.
- Menta para ação positiva, status e destaque.
- Baunilha para superfícies claras e contraste editorial.

## Consequências

- O primeiro scaffold deve nascer com tokens de design EG.
- A demo HM-like deve ser conteúdo/seed, não tema padrão.
- Qualquer tela importada de mockup deve passar por adaptação visual EG.
