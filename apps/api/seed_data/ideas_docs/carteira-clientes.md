# Carteira de Clientes

**Id:** carteira-clientes
**Categoria:** Cockpit

## O que é
O Plano de Controle ativo para gestão do portfólio. A fonte da verdade sobre quais clientes estão ativos, com quais serviços contratados, e as suas configurações específicas de integração (Kommo/ClickUp).

## Detalhe da Absorção
Vive em `clients_config.json`. A partir daqui, o SO provisiona pastas no ClickUp, aciona alertas de churn, e serve como mapa para que squads como o de Análise de Reuniões saibam para qual cliente (e qual pasta no ClickUp) destinar os insights estratégicos extraídos.
