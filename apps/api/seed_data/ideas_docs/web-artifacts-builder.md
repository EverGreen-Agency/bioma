# Web Artifacts Builder (Motor de UI Rica)

**Id:** web-artifacts-builder
**Categoria:** Infra

## O que é
Um ecossistema técnico focado na geração rápida e belíssima de interfaces web (Landing Pages, Cockpits) liderado por IA.

## Detalhe da Absorção
Usa React/Vite/Tailwind amarrado a regras anti-slop ditadas pela Filosofia Visual EG. Permite que um Agente, ao invés de cuspir HTML sujo, monte componentes padronizados com aparência premium, ideal para protótipos de dashboards ou páginas de clientes em horas, não semanas.
