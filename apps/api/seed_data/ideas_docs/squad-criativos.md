# Squad de Criativos

**Id:** squad-criativos
**Categoria:** Squad

## O que é
Agentes focados na ideação e roteirização da matéria-prima publicitária. Transforma a estratégia da conta em variações testáveis.

## Detalhe da Absorção
Gera roteiros para VSLs, variações A/B de Copy para os anúncios e estruturas visuais. Ele consome o dossiê da marca no Vector Store para garantir aderência ao tom de voz do cliente.
