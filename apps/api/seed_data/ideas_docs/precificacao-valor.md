# Precificação por valor/eficiência

**Id:** precificacao-valor
**Categoria:** Commercial

## O que é
A substituição radical do modelo de "Hora/Homem" das agências clássicas.

## Detalhe da Absorção
Se a IA reduz a redação de uma proposta de 4 horas para 4 minutos, cobrar por hora destrói o nosso lucro. Cobra-se um Setup Fee alto (instalação da infra) + um Fee de Estratégia e Mídia. A eficiência ganha pela máquina aumenta a margem bruta da Evergreen, e não barateia o projeto para o cliente.
