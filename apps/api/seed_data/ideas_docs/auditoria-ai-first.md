# Auditoria de Prontidão AI-First

**Id:** auditoria-ai-first
**Categoria:** Service

## O que é
Um serviço consultivo de entrada (Front-End) para diagnosticar se a empresa do lead está pronta para IA.

## Detalhe da Absorção
Audita a organização em 7 dimensões (Qualidade dos Dados, Cultura, Processos Mapeados, Ferramentas, Segurança, etc). Gera um score final e um plano de ataque de 6 meses ("AI-Firstify"). Pode ser cobrado como produto isolado High-Ticket ou servir de isca para o serviço contínuo.
