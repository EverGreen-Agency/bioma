# Editar ideias + ver detalhe / 1 doc por ideia

**Id:** idea-detail-edit
**Categoria:** Cockpit

## O que é
Funcionalidade crucial do dashboard de controle do Banco de Ideias.

## Detalhe da Absorção
O Kanban passou de uma leitura fria do JSON para um sistema modal robusto. Agora é possível não só ler o Documento detalhado em Markdown nativo, como interagir para mover conexões e editar descrições diretamente pela interface, consolidando o Cockpit como ponto único da verdade, substituindo a edição manual via IDE.
