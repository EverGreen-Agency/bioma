# Squad Relatórios de Cliente

**Id:** squad-relatorios
**Categoria:** Squad

## O que é
Um squad especializado em conectar-se às plataformas de mídia e CRM (Meta, Google Ads, Kommo) para extrair os dados e construir uma narrativa estratégica sobre a performance do cliente.

## Detalhe da Absorção
Em vez de montar dashboards engessados, este squad escreve a narrativa do que os números significam. Ele lê os dados brutos via MCPs (integrações seguras) e gera um report executivo que o BI então apenas exibe, poupando tempo de análise do gestor.
