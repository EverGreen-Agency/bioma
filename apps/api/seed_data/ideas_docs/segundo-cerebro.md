# Segundo Cérebro integrado (AI OS)

**Id:** segundo-cerebro
**Categoria:** Infra

## O que é
A fundação conectiva de todo o Evergreen AI OS. Um LLM global com tentáculos nas nossas ferramentas corporativas, atuando como o oráculo da empresa.

## Detalhe da Absorção
Plugado no Google Drive, ClickUp, Kommo, transcrições de reuniões e base de propostas. A ideia é que em vez de um chatbot vazio, qualquer interação com o sistema opere sob um "Contexto 360º" em tempo real sobre a nossa operação.
