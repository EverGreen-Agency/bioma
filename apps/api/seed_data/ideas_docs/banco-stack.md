# Banco de Stack

**Id:** banco-stack
**Categoria:** Infra

## O que é
O "Tech Radar" privado da EG. Um catálogo vivo das tecnologias em uso ou monitoradas para serem aplicadas nos projetos internos e de clientes.

## Detalhe da Absorção
Estruturado em anéis de maturidade: `Assess` (promissor, vamos observar), `Trial` (testando em laboratório agora), `Adopt` (padrão de uso em produção), `Hold` (depreciado ou bloqueado). A Engenharia sugere a entrada de novas techs, as ADRs decidem seu uso, e todos os squads que precisam codar (ex: Procurando ferramenta de DB) consultam este banco.
