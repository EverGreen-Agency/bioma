# Squad Prospector (eg_prospector)

**Id:** squad-prospector
**Categoria:** Squad

## O que é
O esquadrão de Topo de Funil. Focado puramente em caçar as contas-alvo do ICP (Ideal Customer Profile) antes de qualquer proposta comercial.

## Detalhe da Absorção
Sem scraping bruto: opera de forma inteligente usando integrações reais (Apollo, Lusha, Clay via MCPs). Pesquisa os sinais vitais do prospect, calcula um score de fit técnico/comercial e joga as listas de "Hot Leads" direto no Kommo CRM, ativando a necessidade de uma reunião para o Closer assumir.
