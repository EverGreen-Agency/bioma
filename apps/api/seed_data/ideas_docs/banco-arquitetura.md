# Banco de Arquitetura

**Id:** banco-arquitetura
**Categoria:** Infra

## O que é
O documento vivo que consolida a "identidade" de engenharia da EG: o *porquê* as coisas são feitas de determinada forma. Não lista os artefatos, lista os princípios e decisões tomadas.

## Detalhe da Absorção
Fica exposto na aba de Arquitetura do Dashboard junto com um Mapa de Squads gerado dinamicamente. Ele serve de Ground Truth para o Guardião/Arquiteto. Quando há uma dúvida se uma feature deve virar um Agente ou um Script, este banco contém a resposta.
