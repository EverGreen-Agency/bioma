# Squad de Voz do Cliente

**Id:** squad-voz-cliente
**Categoria:** Squad

## O que é
O esquadrão focado na retenção e qualidade do produto. Minera e categoriza feedbacks espalhados em múltiplas plataformas.

## Detalhe da Absorção
Lê tickets de suporte, comentários em anúncios, e-mails e anotações do CRM. Agrupa temas, conta a frequência e elenca prioridades. Este material enriquece o Dossiê do Cliente e é jogado no Vector Store (RAG) para que o copywriter tenha a exata linguagem do público.
