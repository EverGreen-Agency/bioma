# Tag de Ativação / Gatilho de Desenvolvimento

**Id:** tag-ativacao
**Categoria:** Cockpit

## O que é
Um evento visual e sistêmico disparado ao mover um card no Kanban ou via aprovação humana (HITL).

## Detalhe da Absorção
Quando uma ideia atinge o status "pronto p/ desenvolver", um gatilho é acionado. Se o Hub Chat estiver ativo, ele avisa o Dispatcher para rodar o Squad de Engenharia. A regra é rígida: o disparo sempre exige aprovação humana, barrando a IA de sair programando ou enviando e-mails sem consentimento.
