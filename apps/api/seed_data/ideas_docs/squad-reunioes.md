# Squad de Reuniões (squad-reunioes)

**Id:** squad-reunioes
**Categoria:** Squad

## O que é
Esquadrão inteligente para análise de transcripts de conversas com clientes (discovery, kickoff, weekly). Substitui notas de reunião estáticas por extração ativa de inteligência e pendências.

## Detalhe da Absorção
Não faz apenas "resumo" da call. Ele ouve a gravação, extrai as tarefas pendentes, as dores declaradas do cliente, detecta alertas de churn e envia as ações mapeadas diretamente para as inboxes relevantes (seja criando Tasks no ClickUp ou sugerindo novos horizontes no Banco de Ideias). É a porta de entrada para a inteligência de negócios do dia a dia.
