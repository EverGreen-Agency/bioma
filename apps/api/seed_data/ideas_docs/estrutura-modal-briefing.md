# Estrutura Modal de Briefing

**Id:** estrutura-modal-briefing
**Categoria:** Feature

## O que é
A padronização sintética da entrega de relatórios e notificações feitas por Agentes para Humanos.

## Detalhe da Absorção
Agentes têm a tendência de ser verborrágicos (falar demais). Esta feature cria 3 modos rígidos via Prompt Engineering: "Daily" (pontos bala crus da operação), "Topic" (Deep dive sobre uma campanha ou problema), e "Incident" (Gatilho emergencial focado apenas na ação exigida do fundador).
