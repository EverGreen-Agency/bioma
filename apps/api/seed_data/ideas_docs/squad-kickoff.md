# Squad Kickoff Técnico

**Id:** squad-kickoff
**Categoria:** Squad

## O que é
O agente que atua no hiato entre a venda e a execução. Lê o escopo recém-aprovado e monta a árvore inicial de dependências técnicas.

## Detalhe da Absorção
Ele gera as Tasks base no ClickUp e monta o esqueleto do repositório no GitHub para o time de desenvolvimento. Atenção arquitetural: há risco de overlap com o `squad-engenharia`, devendo atuar apenas no setup administrativo, delegando o design de software (SDD) para a engenharia.
