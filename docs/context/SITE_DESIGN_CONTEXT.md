# Contexto de Design e Referências — Site da Evergreen (EG)

## 1. Visão Geral
Este documento consolida as diretrizes de design, inspirações visuais e decisões de interface para o repositório do site institucional da Evergreen (`EG/eg`).

## 2. Referências de Design & Inspiração
- **Huly.io**: Estética dark mode moderna, tipografia limpa, componentes tipo glassmorphism e animações suaves de entrada.
- **Sentry.io**: Hierarquia de texto marcante, prova social clara e paleta com acentos vibrantes.
- **N8n.io**: Apresentação visual de automação/fluxo de trabalho de forma clara e modular.
- **21hrs.space**: Layouts dinâmicos e inovadores com alto impacto de primeira vista.
- **DB Longbow**: Micro-animações e refinamento visual de impacto.

## 3. Diretrizes de Implementação para o Agente (`CLAUDE.md` do repositório do site)
Ao trabalhar no repositório do site (`EG/eg`), o agente deve seguir:
- **Estética Rica & Dark Mode**: Paleta harmoniosa (tons escuros profundos, acentos em gradiente verde/esmeralda).
- **Sem Placeholders**: Utilizar assets reais ou SVGs vetoriais customizados.
- **CSS Nativo / Tailwind v4**: Seguir a stack definida no projeto do site sem introduzir dependências pesadas extras.
- **SEO & Responsividade**: Meta tags completas, OpenGraph e layouts fluidos para mobile e desktop.
