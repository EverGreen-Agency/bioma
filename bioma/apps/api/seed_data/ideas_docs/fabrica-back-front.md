# Fábrica: backoffice vs. frontoffice

**Id:** fabrica-back-front
**Categoria:** Commercial

## O que é
A divisão do trabalho na nova era das agências. Onde alocamos esforço humano vs. esforço de silício.

## Detalhe da Absorção
Todo o Backoffice (criação de projetos no ClickUp, redação de contratos, preenchimento de CRM, confecção burocrática de relatórios) é 100% tratorado por IA. O humano é realocado 100% para o Frontoffice: julgamento crítico, reuniões de relacionamento, negociação e estratégia visual.
