# Princípio: IA se adapta ao cliente

**Id:** ia-adapta-cliente
**Categoria:** Commercial

## O que é
A regra máxima para não gerar fadiga de software nos clientes (Software Fatigue).

## Detalhe da Absorção
Não forçamos o cliente a entrar no nosso portal customizado para ver relatórios se ele detesta mudar de tela. Se ele vive no Slack, nossos agentes mandam o resumo no Slack dele. Se ele usa o Trello em vez do ClickUp, o MCP se adapta e atualiza o Trello dele. A inteligência artificial é injetada na infraestrutura legada do cliente, eliminando objeções na venda.
