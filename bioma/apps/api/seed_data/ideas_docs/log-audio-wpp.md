# Log de áudio via WhatsApp

**Id:** log-audio-wpp
**Categoria:** Feature

## O que é
Interface de voz sem atrito para os colaboradores (Closer, Account Manager) atualizarem o sistema.

## Detalhe da Absorção
O colaborador manda um áudio de 2 minutos no WhatsApp da IA após uma reunião. O sistema transcreve via Whisper, identifica o cliente pelo contexto semântico, resume os próximos passos e injeta a anotação diretamente no ClickUp e no Kommo CRM, dispensando o trabalho braçal de data-entry.
