# Forward Deployed AI

**Id:** forward-deployed
**Categoria:** Service

## O que é
Uma modalidade de serviço High-Ticket para clientes corporativos com paranoia de privacidade (Saúde, Finanças, Jurídico).

## Detalhe da Absorção
Em vez de rodar a inteligência nos nossos servidores batendo na OpenAI, instalamos o sistema dentro da AWS/GCP do cliente rodando modelos Open-Source (Llama, Mistral) on-premise. Toda a IA roda na infraestrutura deles. DNA inspirado em modelos da Palantir.
