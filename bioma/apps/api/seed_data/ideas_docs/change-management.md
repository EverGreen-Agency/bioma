# Change Management no cliente

**Id:** change-management
**Categoria:** Service

## O que é
Um playbook de segurança psicológica para equipes de clientes que sofrem pânico de serem substituídas por IA.

## Detalhe da Absorção
Frequentemente a equipe do cliente sabota a implantação da ferramenta. O processo de Change Management treina o funcionário do cliente, mostrando que a IA tira o trabalho repetitivo, dando a ele o poder de gerenciar a máquina. A meta é que o funcionário promova a ferramenta, reduzindo o churn de software por boicote humano.
