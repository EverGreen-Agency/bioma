# Loop de retroalimentação pós-call

**Id:** loop-pos-call
**Categoria:** Feature

## O que é
A automatização da inteligência de vendas após o término de um pitch de fechamento.

## Detalhe da Absorção
Ouve a transcrição da reunião final, extrai o frame SPICED (Situação, Dor, Impacto, Evento Crítico, Decisão), atualiza o card no Kommo e joga objeções não contornadas no RAG para que os roteiros de anúncios sejam atualizados e rebatam a objeção no top-funil.
