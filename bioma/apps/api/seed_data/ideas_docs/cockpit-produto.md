# Cockpit interno → produto

**Id:** cockpit-produto
**Categoria:** Service

## O que é
A expansão da Evergreen AI OS para além de uma agência de serviços: tornar-se uma empresa de SaaS.

## Detalhe da Absorção
Após rodar e provar o valor do Dashboard Interno (Cockpit) conosco, empacotamos o sistema e vendemos licenças para outras agências ou consultorias gerirem suas próprias operações com a nossa arquitetura de squads. Pivot para receita recorrente pura (MRR).
