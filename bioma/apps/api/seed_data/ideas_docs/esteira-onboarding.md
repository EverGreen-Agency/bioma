# Esteira de Onboarding Automatizada

**Id:** esteira-onboarding
**Categoria:** Feature

## O que é
A materialização prática do `squad-onboarding`.

## Detalhe da Absorção
Quando um negócio é ganho, a esteira executa chamadas em cadeia: cria o Workspace no ClickUp a partir de um template, gera os DoDs, cria a pasta isolada no Google Drive do cliente, convida os e-mails e redige o e-mail de boas-vindas com todos os links. O humano apenas revisa e envia.
