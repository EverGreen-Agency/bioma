# Filosofia Visual EG (Manifesto de Design)

**Id:** filosofia-visual-eg
**Categoria:** Infra

## O que é
O documento de Ground Truth estético. O farol visual da EG, que traduz o feeling de marca premium para o design de software e peças publicitárias.

## Detalhe da Absorção
Estabelece regras rígidas (negative space, cores neutras vibrantes, ausência de ruído genérico). Serve como contexto vital a ser inserido no prompt de qualquer agente de engenharia de frontend ou gerador de imagem, blindando contra resultados visualmente medíocres (slop).
