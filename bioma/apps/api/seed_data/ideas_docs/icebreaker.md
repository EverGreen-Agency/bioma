# Icebreaker de Prospecção

**Id:** icebreaker
**Categoria:** Feature

## O que é
Uma feature do `squad-prospector` que abandona o modelo de "e-mail frio genérico" a favor da entrega de valor instantânea.

## Detalhe da Absorção
Varre o site ou LinkedIn do lead usando um scraper headless. Roda um mini "Raio-X" (vê se o site tá lento, se o pixel tá faltando, se a copy da Hero Section é fraca) e inicia a prospecção não pedindo uma call, mas entregando a análise de graça como gancho de autoridade.
