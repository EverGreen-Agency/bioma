# Squad Onboarding / Kommo / ClickUp

**Id:** squad-onboarding
**Categoria:** Squad

## O que é
O time autônomo responsável pelo provisionamento da infraestrutura do cliente após o fechamento do contrato. 

## Detalhe da Absorção
Assim que a proposta é dada como "Ganho" no Kommo, este squad assume. Ele cria as pastas do cliente no ClickUp, configura os campos customizados no CRM, e inicializa o `clients_config.json`. Já existe parcialmente sob a alcunha de `eg_setup`.
