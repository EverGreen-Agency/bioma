# Máquina Completa (upsell de infra)

**Id:** maquina-completa
**Categoria:** Commercial

## O que é
Nossa tese central de vendas. Não vendemos gestão de tráfego, vendemos arquitetura de vendas.

## Detalhe da Absorção
No discurso comercial, o produto final é a infraestrutura montada (Anúncio -> WhatsApp com IA qualificador -> Reunião agendada no Kommo). Vender o ecossistema reduz churn porque o cliente percebe que está comprando uma máquina corporativa operada pela agência, e não um freela que clica botões no Facebook Ads.
