# VoIP inteligente de qualificação

**Id:** voip-qualificacao
**Categoria:** Service

## O que é
A evolução do SDR humano. Um agente autônomo baseado em voz que liga ativamente para os leads.

## Detalhe da Absorção
Integração de ElevenLabs (voz ultrarrealista com latência mínima) e Twilio (telefonia). O agente liga para leads de formulário em menos de 5 minutos, faz o filtro BANT (Budget, Authority, Need, Timing) conversando naturalmente, e se qualificado, envia um link do Calendly para marcar com o Closer.
