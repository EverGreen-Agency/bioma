# Skill squad-creator-EG

**Id:** skill-squad-creator
**Categoria:** Infra

## O que é
A formalização do processo de "nascer um novo squad" (Scaffolder) em uma skill padronizada do sistema.

## Detalhe da Absorção
Lê o Banco de Arquitetura e gera automaticamente a estrutura de pastas, os arquivos `.agent.md`, as configurações e o `Definition of Done` (DoD) de um esquadrão nascente. Substitui a criação de arquivos na mão.
