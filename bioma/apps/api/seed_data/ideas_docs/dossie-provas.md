# Dossiê de Provas de Confiança

**Id:** dossie-provas
**Categoria:** Feature

## O que é
Um agente focado na construção de autoridade (Case Studies) automatizada.

## Detalhe da Absorção
O agente varre o GA4 e o Meta Ads dos clientes semanalmente. Encontrando anomalias positivas (ex: ROAS subiu 40%), ele tira "prints" de dados, gera um mini-relatório do que foi feito e joga no Banco do Vector Store. Isso é consumido pela criação de propostas futuras para clientes do mesmo nicho.
