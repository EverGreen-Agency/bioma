# Skill brand-guidelines-EG

**Id:** skill-brand-eg
**Categoria:** Infra

## O que é
A padronização estética obrigatória incorporada em um Skill reutilizável por qualquer squad.

## Detalhe da Absorção
Garante que todo artefato gerado (seja um dashboard no React, um PDF de proposta ou um doc Markdown) aplique a identidade visual da EG: paleta musgo/menta/baunilha, tipografia Helvetica Neue e o tom de voz "Boutique". É a evolução lógica do `eg_style.js` para um agente independente.
