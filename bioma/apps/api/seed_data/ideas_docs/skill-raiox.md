# Skill raio-x-skill

**Id:** skill-raiox
**Categoria:** Infra

## O que é
Transformação do relatório do Raio-X numa Skill portátil que pode ser invocada por outros esquadrões.

## Detalhe da Absorção
Em vez de ter um squad exclusivo, a função central de aplicar a auditoria nos 3 Pilares (Oferta/Demanda/Conversão) e gerar o scoring pode ser invocada como skill pelo `squad-prospector` (Top Funnel) ou pelo `squad-hunter` (Bottom Funnel) dependendo do nível de dados disponíveis do cliente.
