# ClickUp Direct Injector (Client Insights)

**Id:** clickup-direct-injector
**Categoria:** Feature

## O que é
Uma rodovia expressa para transformar relatórios de IA em itens acionáveis sem fricção.

## Detalhe da Absorção
Em vez de gerar um PDF para o analista ler, o squad analítico (após processar GA4 e encontrar um insight para anúncio) empurra esse insight diretamente para o ClickUp do cliente, como uma "Task" na lista "Backlog de Ideias do Cliente". Pula o banco da EG e vai direto para a esteira operacional do tráfego.
