# Captação multi-plataforma de propostas

**Id:** multi-plataforma-freelance
**Categoria:** Feature

## O que é
Uma ferramenta de ingestão de oportunidades de plataformas como Upwork, Malt e Contra para o pipeline de vendas da agência.

## Detalhe da Absorção
A Fase 1 é semi-manual (colar URL no dashboard para contornar bloqueios de scraper). A Fase 2 envolve usar o n8n ou Zapier lendo RSS feeds de buscas salvas do Upwork e batendo em um Webhook do Opensquad, populando o Kommo CRM automaticamente com leads quentes.
