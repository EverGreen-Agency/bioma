# Squad Raio-X Automatizado

**Id:** squad-raiox
**Categoria:** Squad

## O que é
A automação do nosso framework principal de auditoria comercial. Coleta os dados de um lead prospectado e diagnostica as três frentes do funil.

## Detalhe da Absorção
Analisa Oferta (Copy/Página), Demanda (Tráfego/Mídia) e Conversão (CRM/Atendimento). Gera um score automático e o relatório de gargalo que será usado pelo Closer na reunião de vendas para ancorar a autoridade da agência.
