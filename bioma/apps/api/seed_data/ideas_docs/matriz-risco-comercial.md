# Matriz de Risco Comercial (Lead Scoring)

**Id:** matriz-risco-comercial
**Categoria:** Commercial

## O que é
Framework estrito para impedir a agência de assumir clientes tóxicos ou não-escaláveis.

## Detalhe da Absorção
Cruza Probabilidade de Sucesso Técnico x Severidade Operacional. Avalia via IA os inputs da prospecção: O nicho permite margem? O cliente tem maturidade digital? Se o score bate na zona de risco vermelha, o lead é desqualificado imediatamente (refugo automático), salvando o time de dor de cabeça futura.
