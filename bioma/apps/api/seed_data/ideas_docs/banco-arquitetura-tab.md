# Aba Banco de Arquitetura no dashboard

**Id:** banco-arquitetura-tab
**Categoria:** Cockpit

## O que é
A visibilidade da malha estrutural do sistema em ambiente UI.

## Detalhe da Absorção
Atualmente a arquitetura repousa num arquivo `.md` no backend. Esta ideia propõe uma aba dedicada no Dashboard, renderizando a árvore de Squads, MCPs e permissões. Serve para que diretores e arquitetos acompanhem visualmente a topologia e as capacidades reais do ecossistema, ajudando no onboarding de novos engenheiros.
